# External Sources & References

1. **FastAPI**:
   - Modern, fast web framework for building APIs with Python 3.8+.
   - Documentation: https://fastapi.tiangolo.com/

2. **FFmpeg & FFprobe**:
   - Complete, cross-platform solution to record, convert and stream audio and video.
   - Gyan.dev Windows Builds: https://www.gyan.dev/ffmpeg/builds/
   - Filter documentation (`trim`, `setpts`, `atempo`, `concat`, `drawtext`): https://ffmpeg.org/ffmpeg-filters.html

3. **Pydantic**:
   - Data validation and settings management using Python type annotations.
   - Documentation: https://docs.pydantic.dev/

4. **SQLite**:
   - Self-contained, serverless, zero-configuration SQL database engine used for robust local session, asset, and render job persistence.
   - Documentation: https://www.sqlite.org/

5. **Static FFmpeg & ImageIO**:
   - Automated native binary distribution for self-contained, reproducible execution on Windows.
   - Static FFmpeg documentation: https://pypi.org/project/static-ffmpeg/
